# Load Testing

## Initial target

- 50 simultaneous teacher sessions
- 2,000 students
- 100,000 activity rows
- Concurrent attendance and point awards

## Measure

- p50 and p95 response time
- error rate
- database connections
- Realtime channel count
- query execution time
- browser memory and render time

## Pass conditions

Pass conditions must be defined before the run. Retain scripts, dataset description, raw output, and environment details in `09 - Evidence/Test Results`.
