# Admin Lifecycle

## Create

1. Create or authenticate a normal account.
2. Existing admin promotes it through protected logic.
3. Record the decision and audit event.
4. Verify the new admin in a fresh session.

## Replace

1. Promote replacement.
2. Verify replacement access.
3. Transfer churches and classes.
4. Confirm no remaining ownership.
5. Disable or delete the old account according to policy.

## Remove

Never remove the final administrator. Never delete an owner before transferring their data.
