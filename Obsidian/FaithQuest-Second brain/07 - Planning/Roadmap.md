# Roadmap

## Phase 1 — Security foundation

- Secure profile creation and role changes.
- Protect the final administrator.
- Replace destructive owner cascades.
- Add account ownership-transfer flow.

## Phase 2 — Reliable multi-user data

- Make Supabase authoritative.
- Replace whole-state sync with explicit operations.
- Add student badge persistence.
- Add transactional attendance and reward redemption.
- Add scoped Realtime updates.

## Phase 3 — Quality and scale

- Restore lint and automated tests.
- Add RLS and browser integration tests.
- Move analytics aggregation to PostgreSQL.
- Run concurrency and load tests.

## Phase 4 — Production readiness

- Verify backups and restores.
- Establish monitoring and incident response.
- Rehearse deployment and rollback.
- Obtain user acceptance.
