# Glossary

| Term | Meaning |
|---|---|
| Admin | Authorized account with organization-wide management access |
| Teacher | Account that manages its own classes and students |
| Classroom | Live teacher workspace for attendance, points, quizzes, badges, and rewards |
| RLS | Row-Level Security; PostgreSQL rules that decide which rows a user may access |
| Source of truth | The authoritative version of data |
| RPC | A protected PostgreSQL function called through Supabase |
| Realtime | Supabase change notifications sent to connected clients |
| ADR | Architecture Decision Record |
| Release gate | A required check that must pass before deployment |
| Evidence boundary | The limit of what a test or observation actually proves |
